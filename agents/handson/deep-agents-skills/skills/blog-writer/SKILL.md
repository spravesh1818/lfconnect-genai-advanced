# blog-writer

## Overview

This skill helps write clean, engaging blog-style content.

## When to use
Use this skill when the user asks for:
- a blog post
- a blog intro
- an article introduction
- an engaging educational write-up
- polished public-facing writing

## Instructions

When using this skill:

1. Start with a strong hook.
2. Keep the writing clear and readable.
3. Prefer short paragraphs.
4. Make the tone engaging, slightly polished, and teacher-friendly.
5. End with a transition that invites the reader into the next section.
6. Do not sound academic unless the user explicitly asks for it.

## Output style

Preferred structure:
- Hook
- Context
- Why it matters
- Transition

# writer-skill

## When to use
Use this skill when the task is to write a clear first draft from research notes.

## Instructions
1. Start with a strong opening.
2. Write in short paragraphs.
3. Keep the flow logical: intro, core points, close.
4. Prefer clarity over cleverness.
5. Do not invent facts that are not present in the input.

# publisher-skill

## When to use
Use this skill when turning edited text into the final publication-ready output.

## Instructions
1. Add a title.
2. Add section headings when helpful.
3. Make formatting clean and easy to scan.
4. Preserve the edited content faithfully.
5. End with a short summary block if useful.
